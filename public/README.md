## 🛠️ Technical Architecture & Features

- **Agentic AI Frameworks**: Built using OpenAI Agents SDK, CrewAI, LangChain, and MCP Protocol.
- **Enterprise SEO Engine**:
  - Full Schema.org JSON-LD graph (`Organization`, `WebSite`, `Service`, `FAQPage`).
  - Open Graph & Twitter Card rich metadata preview tags.
  - Dedicated `robots.txt`, `sitemap.xml`, and `site.webmanifest` PWA configuration.
- **Interactive AI Chatbot**: Powered by Google Gemini with client-side markdown link parsing for instant WhatsApp & Contact Form redirection.
- **Lightweight Zero-Build Frontend**: Vanilla HTML5/CSS3 design system with custom CSS tokens, smooth scroll reveal animations, and 100% mobile responsiveness.
- **Serverless API Layer**: Contact SMTP forwarder and Chatbot proxy endpoints designed for Vercel serverless execution.

## 💻 Local Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Shafqatsarwar/excellencliks.git
   cd excellencliks
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure environment variables**:
   Create a `.env` file in the root directory (see `developer_guid.md` for variable reference).

4. **Run the local Express server**:
   ```bash
   node server.js
   ```
   Open `http://localhost:3000` in your web browser.
